# GetMan - 代码库基本信息

## 项目标识

- **名称**: GetMan
- **版本**: 0.1.0
- **标识符**: com.getman.app
- **描述**: 极简轻量的 API 测试桌面应用
- **定位**: 对标 Postman，去除臃肿功能，专注核心体验

## 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 桌面框架 | Tauri | 2.x |
| 前端框架 | React | 19.x |
| 语言 (前端) | TypeScript | 5.8.x |
| 构建工具 | Vite | 7.x |
| 状态管理 | Zustand | 5.x |
| 语言 (后端) | Rust | 2021 edition |
| 数据库 | SQLite (rusqlite) | 0.32 |
| HTTP 客户端 | reqwest | 0.12 |
| 序列化 | serde + serde_json | 1.x |
| 异步运行时 | tokio | 1.x |
