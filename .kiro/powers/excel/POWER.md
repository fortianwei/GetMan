# Excel 文件操作

读取和分析本地 Excel 文件（.xlsx / .xls）。

## MCP 工具

| 工具 | 用途 |
|------|------|
| `read_data_from_excel` | 从 Excel 文件读取数据 |

## 注意事项

- 文件路径需使用绝对路径或相对于工作目录的路径
- 确保文件未被其他程序占用
